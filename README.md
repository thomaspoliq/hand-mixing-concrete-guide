# How to Mix Concrete by Hand in a Wheelbarrow

A practical guide to hand mixing small batches of concrete in a wheelbarrow: the right order for adding sand, aggregate, cement and water, simple mix ratios for common garden jobs, how to judge consistency by eye and feel, and a worked example that turns a small slab into a bag count.

## Deploying this page

The finished page is `index.html`, a single self-contained file with no external assets. It can be deployed as a static site (GitHub Pages, Vercel or Netlify) or served through the included Streamlit app (`app.py`, needs `streamlit` from `requirements.txt`).
